## 短い発話の脱落（2026-10-03 修正）

利用者の実発話「あいうえお」（1.4 秒）が "I will" になった。合成音声でも「こんにちは」「テスト」「はい」「ありがとう」が空で返ることを再現。
原因は WhisperKit が各解析区間の末尾 1 秒を切り捨てる既定動作（`windowClipTime: 1.0`）で、1 秒未満の発話は無視され、
1.4 秒の発話は冒頭 0.4 秒しか解析されていなかった。認識前に末尾へ 1.2 秒の無音を足して解消。

| 発話 | 修正前 | 修正後 |
|---|---|---|
| こんにちは | （空） | こんにちは |
| テスト | （空） | テスト |
| はい | （空） | はい。 |
| ありがとう | （空） | ありがとう。 |
| 了解です | 了解です。 | 了解です。 |
| あいうえお | （空） | あいゆえよ（意味のない音の並びは合成音声でも不正確） |

長文 10 本と無音 3 秒は修正後も結果が変わらないことを確認。
